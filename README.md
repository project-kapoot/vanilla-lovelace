# Projet KaPoot - Groupe Lovelace

Site internet pour pouvoir créer et participer à des quiz en ligne avec d'autres joueurs. Projet d'apprentissage réalisé dans le cadre d'une réunion d'apprenants sur le Discord Entraide && Motivation.

## Stack technique 

- Javascript
- CSS
- PHP

## Prérequis

Afin de pouvoir cloner et installer ce projet en local, vous devrez valider les prérequis suivants :

- avoir installé [NodeJs](https://nodejs.org/en) et [NPM](https://www.npmjs.com/). 

Vous pouvez vérifier l'installation de ces deux composants à l'aide des commandes suivantes : `node -v` pour Nodejs et `npm -v` pour NPM

- avoir installé [Composer](https://getcomposer.org/)

Vous pouvez vérifier l'installation de Composer en utilisant la commande suivante : `composer --version`

- avoir installé [PHP](https://www.php.net/), version 8.0 ou supérieur

Vous pouvez vérifier l'installation de PHP en tapant `php -v`

NB : ces commandes partent du principe que vous avez installé ces composants et rajoutés leurs fichiers binaires dans les variables d'environement PATH de votre système d'exploitation

## Installation des dépendances

Concernant les dépendances frontend, lancez la commande : `npm install`

Concernant les dépendances backend, lancez la commande : `composer install`
